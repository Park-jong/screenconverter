# Converter

화면 위에 투명한 틀(오버레이 창)을 올려 두면, 틀 안쪽에 보이는 화면이 실시간으로 모자이크·흑백·픽셀 도트·ASCII 아트 등으로 변환되어 보이는 Windows 용 프로그램입니다. (Java 17, Swing, JNA)

**작동 원리**: 창 가운데 영역의 *아래쪽 화면*을 `java.awt.Robot`(화면 캡처)으로 초당 약 30번 읽어 효과를 적용한 뒤 그 자리에 그립니다. 창이 자기 자신을 다시 찍으면 거울 현상이 생기므로, `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)`로 이 창을 화면 캡처에서 제외합니다.

## 요구사항

- Windows 10 버전 2004 이상 (자기 창 제외 API `WDA_EXCLUDEFROMCAPTURE` 지원 버전). **개발과 검증은 Windows 11에서만 했습니다.**
- JDK 또는 JRE 17 이상 (`java`가 PATH에 있어야 `dist\run.bat`가 동작합니다).

## 실행 방법

1. `dist\run.bat`를 더블클릭합니다. (콘솔 창 없이 실행됩니다.)
2. 오류를 확인하거나 fps를 보고 싶으면 `dist\run-console.bat`, 60fps는 `dist\run-60fps.bat`, 프레임 제한 없음(CPU 많이 사용)은 `dist\run-max.bat`입니다.
3. `.bat` 뒤에 JVM 옵션을 붙일 수도 있습니다. 예: `run.bat -Dconverter.fps=45`

소스에서 빌드하려면 JDK 17 이상과 Maven이 필요합니다.

```
mvn -B package
```

`target\converter.jar`(모든 의존성이 들어간 실행 가능 jar)가 만들어지고 `java -jar target\converter.jar`로 실행할 수 있습니다. `tools\make-dist.bat`를 실행하면 빌드 후 `dist\` 폴더(jar, 실행 .bat, README)를 다시 만듭니다. Maven이 PATH에 없으면 `MVN` 환경변수에 `mvn.cmd` 전체 경로를 지정하세요.

## 사용법

- **이동·크기 조절**: 일반 Windows 창과 같습니다. 제목줄을 끌어 옮기고, 가장자리·모서리를 끌어 크기를 바꿉니다. 최소 창 크기는 518x427입니다.
- **변환 대상**: 창 **가운데 영역**의 *바로 아래 화면*이 변환되어 그 자리에 표시됩니다. 변환할 화면(동영상, 사진, 게임 창 등) 위에 창을 올리면 됩니다. 창을 옮기면 변환 대상도 따라 움직입니다.
- **오른쪽 메뉴**(폭 180px): 위에서부터 효과 목록, 옵션 영역, 일시정지 / 텍스트 복사 / 이미지 저장 / 항상 위 버튼, 그리고 짧은 상태 문구(약 2.5초 뒤 사라짐) 줄입니다. 창 제목에는 현재 효과 이름이 `Converter - 모자이크`처럼 표시됩니다.
- 처음 시작하면 2번 모자이크가 선택되어 있습니다. 시작 크기는 640x360이지만 최소 창 크기보다 작으면 자동으로 늘어납니다.

### 효과 목록

| 번호 | 이름 | 옵션 |
|---|---|---|
| 1 | 원본 | 없음 |
| 2 | 모자이크 | 블록 크기 (2~64, 2 단위, 기본 10) |
| 3 | 흑백 | 없음 |
| 4 | 흑백 2색 | 임계값 (0~255, 기본 128, `+`/`-` 키는 8씩 증감하며 끝에서는 0 또는 255에 맞춰짐) |
| 5 | 도트 16색 | 블록 크기 (2~64, 기본 8) |
| 6 | 도트 게임보이 | 블록 크기 (2~64, 기본 8) |
| 7 | 도트 격자 | 블록 크기 (4~64, 기본 8) |
| 8 | 도트 16색+격자 | 블록 크기 (4~64, 기본 8) |
| 9 | ASCII 아트 | 칸 크기 (8x16 / 6x12 / 4x8, 기본 8x16), 줄 끝 공백 제거 (켜짐/꺼짐, 기본 꺼짐) |

### 옵션 영역

선택한 효과의 옵션만 보입니다. 옵션 종류는 세 가지입니다.

- **슬라이더**: 숫자 값 (블록 크기, 임계값). 트랙을 클릭하거나 끌면 가장 가까운 단위 값으로 맞춰집니다.
- **선택 버튼**: 여러 값 중 하나 (ASCII 칸 크기).
- **체크 토글**: 켜짐/꺼짐 (줄 끝 공백 제거. 복사할 텍스트에만 영향을 주고 화면은 바뀌지 않습니다).

옵션 값은 효과별로 기억됩니다. 다른 효과로 갔다가 돌아와도 값이 유지됩니다. 효과 5~8번의 팔레트(EGA 16색 / 게임보이 4색 / 없음)와 격자 유무는 번호로 고르며, 옵션으로는 바꿀 수 없습니다.

### 메뉴 버튼

- **일시정지 (Space)**: 현재 화면을 멈춥니다. 멈춘 상태에서 효과·옵션을 바꾸면 멈춘 화면에 새 효과가 다시 적용됩니다. 일시정지 중에는 창 제목에 `[일시정지]`가 붙습니다. 일시정지 중 창을 옮기거나 크기를 바꿔 캡처 영역이 달라지면 **자동으로 해제**되고 상태 줄에 "창 변경: 일시정지 해제"가 표시됩니다.
- **텍스트 복사 (Ctrl+C)**: 지금 보이는 ASCII 아트를 텍스트로 클립보드에 복사합니다. **ASCII 아트(9번)에서만 활성**입니다.
- **이미지 저장**: 지금 보이는 변환 결과를 PNG로 저장합니다 (단축키 없음, 모든 효과에서 사용 가능). 아래 "이미지 저장" 참고.
- **항상 위: 켜짐/꺼짐**: 창을 다른 창 위에 고정할지 정합니다 (단축키 없음, 기본 켜짐). 이 설정은 창의 캡처 제외에는 영향을 주지 않도록 구현했습니다.

## 단축키

창이 포커스를 가지고 있을 때 동작합니다.

| 키 | 동작 |
|---|---|
| `1` ~ `9` (숫자 패드 포함) | 해당 번호의 효과 선택 |
| `+` / `-` (`=`, `Shift+=`, 숫자 패드 `+`/`-` 포함) | 선택한 효과의 **첫 번째 숫자/선택 옵션**을 한 단계 올림/내림 (모자이크·도트 블록 크기, 흑백 2색 임계값, ASCII 칸 크기). 옵션이 없는 효과(1, 3번)에서는 아무 일도 없습니다. ASCII는 `+`가 더 작은 칸(8x16 → 6x12 → 4x8)입니다. |
| `Space` | 일시정지 / 재개 |
| `Ctrl+C` | ASCII 텍스트 복사 (ASCII 아트에서만 의미 있음) |
| `ESC` | 프로그램 종료 |

**단축키가 없는 버튼**: 이미지 저장, 항상 위, 그리고 옵션 영역의 체크 토글(줄 끝 공백 제거)과 두 번째 이후 옵션. 이들은 마우스로만 조작합니다. 창 안(가운데 영역)에서 마우스 오른쪽 버튼을 누르면 "닫기" 메뉴가 나옵니다.

## ASCII 아트 사용 팁

- 9번을 선택하면 화면이 칸(기본 8x16 픽셀)별 밝기에 맞는 문자(어두운 칸은 `@#8&` 같은 빽빽한 문자, 밝은 칸은 `.` 또는 공백)로 바뀝니다. 흰 배경에 검은 글자이며 글꼴은 Consolas(없으면 Courier New)입니다.
- **복사**: `Ctrl+C` 또는 "텍스트 복사" 버튼. 복사되는 것은 *그 순간 화면에 보이는 프레임*의 글자입니다. 정지 상태로 복사하고 싶으면 먼저 `Space`로 일시정지하세요.
- **붙여넣기**는 **고정폭 글꼴**(Consolas, Courier New, D2Coding 등)을 쓰는 곳(메모장 + 글꼴 변경, 코드 편집기, 터미널)에서 해야 모양이 맞습니다. 비례폭 글꼴에서는 줄이 어긋납니다. 줄 바꿈 자동 맞춤(워드랩)은 끄세요.
- **칸 크기**: 8x16(기본, 글자 수가 적고 가볍다) / 6x12 / 4x8(촘촘하지만 글자 수가 많다). 칸이 작을수록 가로 글자 수가 늘어나므로 붙여넣는 곳의 한 줄 폭이 충분한지 확인하세요.
- 줄 끝 공백이 불필요하면 "줄 끝 공백 제거"를 켜고 복사하세요.

## 이미지 저장

- 위치: `<사용자 폴더>\Pictures\Converter` (보통 "내 사진\Converter"). 폴더가 없으면 자동으로 만들고, 만들 수 없으면 `<사용자 폴더>\Converter`에 저장합니다. 사진 폴더를 다른 곳으로 옮겨 쓰는 PC에서는 Java가 보는 `user.home\Pictures`와 실제 "내 사진" 위치가 다를 수 있습니다 (검증하지 않음). `-Dconverter.saveDir=폴더경로`로 직접 지정할 수 있습니다.
- 파일명: `converter-yyyyMMdd-HHmmss.png` (예: `converter-20261016-153045.png`). 같은 이름이 이미 있으면 `-1`, `-2`가 붙습니다 (덮어쓰지 않음).
- 결과는 상태 줄에 "저장됨 (Pictures\Converter)" 또는 "저장 실패 (이유)"로 표시되고, 마지막 저장 경로는 버튼에 마우스를 올리면 툴팁으로 나옵니다. 저장 중에 다시 누르면 "저장 중..."이 표시되고 무시됩니다.
- **이 버튼이 있는 이유**: 이 창은 화면 캡처에서 제외되어 있으므로 Windows 캡처 도구, `PrintScreen`, 화면 녹화 프로그램으로는 변환된 결과 창이 찍히지 않고 (창 자리에 아래쪽 원본 화면이 찍힙니다), 변환 결과를 남기려면 이 버튼을 써야 합니다.

## 실행 옵션

`java` 명령에서 `-D이름=값` 형식으로 `-jar` **앞에** 지정합니다. (`run.bat` 뒤에 붙여도 됩니다.)

| 이름 | 기본값 | 설명 |
|---|---|---|
| `converter.fps` | `30` | 목표 프레임 수. `1`~`240` (범위를 벗어나면 이 범위로 맞춤), `max` 또는 `0`은 제한 없음(CPU 많이 사용). 숫자가 아닌 값은 30으로 처리. |
| `converter.metrics` | 꺼짐 | `true`면 5초마다 콘솔(표준 출력)에 fps, 프레임 간격, 캡처·효과 시간 등을 출력. `run-console.bat`에서 볼 수 있습니다. 환경변수 `CONVERTER_METRICS=true`로도 켤 수 있습니다. |
| `converter.bounds` | 지정 안 함 | 창 위치·크기를 `x,y,w,h`(예: `100,100,800,500`)로 지정. 쉼표로 나눈 값이 4개가 아니면 무시하고, 숫자가 아니면 시작 시 오류가 납니다. 최소 창 크기보다 작게 주면 최소 크기로 늘어납니다. |
| `converter.saveDir` | `<사용자 폴더>\Pictures\Converter` | 이미지 저장 폴더. |
| `swing.bufferPerWindow` | `true` (프로그램이 직접 설정) | 창 폭을 넓힌 뒤 오른쪽 메뉴 화면이 갱신되지 않던 문제를 막기 위해 시작할 때 `true`로 설정합니다. 사용자가 직접 지정하면 그 값을 따릅니다. |

## 한계와 알려진 사항

- **검증 범위는 Windows 11, 화면 배율 100%, 모니터 1대뿐입니다.** 배율 125%/150%(DPI)와 다중 모니터는 **구현하지 않았고 검증하지 않았습니다.** 그런 환경에서는 변환 영역이 어긋나거나 다른 모니터가 잘못 캡처될 수 있습니다.
- **원격 데스크톱·구형 Windows**(10 2004 미만)에서는 자기 창 제외가 안 될 수 있습니다. 이 경우 창 제목에 `(제외 실패)`가 붙고 콘솔에 경고가 출력되며, 창이 자기 자신을 캡처하는 거울 현상이 생길 수 있습니다 (프로그램은 계속 실행됨). 원격 데스크톱·구형 Windows에서의 동작은 **이 PC에서 검증하지 않았습니다.**
- 화면 캡처는 `java.awt.Robot`(GDI 방식)입니다. DRM 보호 영상이나 전체 화면 독점 모드 게임 같은 보호·독점 화면은 캡처되지 않고 검은 화면으로 나올 가능성이 있습니다. **이 PC에서 확인하지 않았으며 사실로 단정할 수 없습니다.** 가능하면 창 모드 또는 테두리 없는 창 모드를 사용하세요.
- 최소 창 크기는 518x427입니다 (메뉴 항목이 늘어 커짐).
- CPU 사용량은 기본 30fps에서 코어 1개 기준으로 대략 640x360 약 13%(모자이크, 정적 화면), 1280x720 약 29%(ASCII 아트)입니다 (5단계에서 한 PC에서 측정한 값이며 PC마다 다릅니다). 60fps나 `max`는 더 많이 사용합니다.
- `dist\` 폴더를 옮길 때 폴더 이름에 `%` 문자가 들어가면 `run.bat`이 실패할 수 있습니다(확인하지 않았으니 가능하면 피하세요). 공백, 한글, `&`, 괄호가 들어간 경로는 시험했고 동작했습니다.
- `-Dconverter.metrics=false`를 직접 주면 환경변수 `CONVERTER_METRICS`보다 우선합니다.
- 실제 동영상·게임을 보면서의 체감 부드러움은 측정값 외에 사용자가 직접 확인해야 합니다.
- DWM이 합성하는 화면에서의 육안 확인은 자동 검증이 불가능해 사용자 확인이 필요한 항목으로 남아 있습니다.

## 문제 해결

| 증상 | 해결 |
|---|---|
| `run.bat`을 눌러도 창이 안 뜸 | `run-console.bat`로 실행해 메시지를 확인하세요. `Java was not found`이면 JDK/JRE 17 이상을 설치하고 PATH에 추가하세요. `version 17 or newer is required`이면 더 높은 버전의 Java를 PATH 앞쪽에 두세요. |
| 제목에 `(제외 실패)`가 보이고 화면이 겹쳐 보임(거울) | 원격 데스크톱이거나 Windows 10 2004 미만일 수 있습니다. 로컬 PC의 최신 Windows에서 실행하세요. |
| 창을 넓힌 뒤 메뉴 화면이 안 바뀜 | 이미 수정되었습니다 (`swing.bufferPerWindow=true`를 자동 설정). 그래도 재현되면 `run-console.bat` 출력과 함께 알려 주세요. |
| `ESC`, 숫자 키가 안 먹음 | 창이 포커스를 잃은 상태입니다. 창을 한 번 클릭한 뒤 다시 누르세요. |
| 너무 느리거나 CPU가 높음 | 창을 작게 하거나, 효과 9(ASCII)를 피하거나, `-Dconverter.fps=15` 등으로 낮추세요. |

## 개발자 안내

패키지 구성은 `com.converter.effect`(변환 효과와 옵션·효과 등록부 `EffectRegistry`), `capture`(화면 캡처, 프레임 속도 조절 `FramePacer`, 계측 `FrameMetrics`), `ui`(오버레이 창 `OverlayWindow`, 오른쪽 메뉴 `MenuPanel`, 텍스트 복사·이미지 저장), `win32`(JNA로 호출하는 `SetWindowDisplayAffinity`)입니다. 진입점은 `com.converter.Main`입니다. 테스트와 빌드는 `mvn -B package`로 함께 실행됩니다. 계측·측정용 도구(움직이는 패턴 창, 기준선 측정)는 `src/test/java/com/converter/tools`에 있습니다. 개발 기록은 `ROADMAP.md`(단계별 진행 상황)와 `agent-summaries/`(단계별 개발·검증·피드백 요약)에 있습니다. 이 문서의 `ROADMAP.md`, `agent-summaries/`, `tools\make-dist.bat`, `src\` 경로는 **소스 폴더 기준**이며 `dist\` 폴더 안에는 들어 있지 않습니다.
