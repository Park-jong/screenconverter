# 3-1 개발: 자기 창 제외 (code-writer 보고, 메인 에이전트가 대신 저장)

`mvn -B package` BUILD SUCCESS, 테스트 9개 통과(기존 6 + 신규 3). 실측 뒤 java 프로세스 0개. 리뷰 판정 없음.

## 변경
- `win32/DisplayAffinity.java`: 인터페이스 `boolean excludeFromCapture(Component)` (JNA 타입 비노출).
- `win32/AffinityFlags.java`: 패키지 전용 순수 로직. WDA_NONE=0, WDA_MONITOR=1, WDA_EXCLUDEFROMCAPTURE=0x11, `isExcluded(int)`.
- `win32/WindowsDisplayAffinity.java`: JNA 구현. `Native.getComponentPointer`로 HWND(null이면 false), `Native.load("user32", ..., W32APIOptions.DEFAULT_OPTIONS)`로 Set/GetWindowDisplayAffinity, 0x11 설정 후 되읽어 `isExcluded` 반환. Set/Get 실패 시 GetLastError를 System.err 한 줄(정상 경로는 출력 없음). 비 Windows·UnsatisfiedLinkError·RuntimeException은 catch해 false.
- `ui/OverlayWindow.java`: `volatile boolean captureExcluded` + `setCaptureExcluded`/`isCaptureExcluded`. `captureOnce` 주석을 실제 결과(display affinity로 제외, 숨기기 불필요)로 갱신. onShown 순서·MinimumWindowSize·MIN_CAPTURE·closeApp·창 장식 불변.
- `Main.java`: `setShownHook`에 `window.setCaptureExcluded(affinity.excludeFromCapture(window))` 등록.
- 신규 `test/.../win32/AffinityFlagsTest.java`: 상수, 판정, null 창이 예외 없이 false.

## Robot 실측 (사실 보고, 배율 1.0, 단일 모니터)
하네스 scratchpad의 H.java. 순수 `RobotScreenGrabber`(래핑 없음), 패턴 `pat(x,y)=((7x)&255,(5y)&255,(3(x+y))&255)`(화면 좌표 기준) undecorated JFrame 위에 OverlayWindow를 놓고 `captureRect ∩ 패턴 프레임` 전수 비교 + 오버레이 바깥 전체(제목줄·테두리 포함) 비교.
- affinity 미적용(off): captureRect 전체 픽셀이 패턴과 다름(자기 자신 캡처 이미지를 그림 → 양성 대조). 내부색 (40,40,40)·테두리색 (200,200,200) 검출 수는 0~1개로 의미 약함 → 판단은 bad 수 기준.
- affinity 적용(on): `excluded=true`, captureRect bad=0, (40,40,40)·(200,200,200) 미검출, 예상 밖 검은 픽셀 0.

| 경우 | captureRect | 비교 픽셀 | off bad | on bad |
|---|---|---|---|---|
| initial | 442x319 | 140998 | 140998 | 0 |
| moved | 442x319 | 140998 | 140998 | 0 |
| resized (777x555) | 579x514 | 297606 | 297606 | 0 |
| 최소 (518x221) | 320x180 | 57600 | 57600 | 0 |
| 최대화 | 1738x1007 (프레임 교집합 960000) | 960000 | 960000 | 0 |

- 제외된 자리는 검은색이 아니라 뒤쪽 패턴이 나옴. 오버레이 외곽 전체(제목줄·테두리 포함)도 on 상태 bad=0 (외곽 검은 픽셀 2~12개는 모두 패턴 값 자체가 (0,0,0)인 자리).
- 하네스는 Main.java 를 거치지 않고 `setShownHook` 직접 등록. `java -jar` 종료 코드·stderr 확인은 하지 않음.

## 미실시·한계
DPI 125/150%, 다중 모니터, 장시간 가동, 이동 중 연속 프레임 비교(정지 후 1회 캡처만). 5px 둥근 모서리는 3단계 판정과 분리(이번 비교에서는 문제 미발생). ROADMAP 진행표·위험도 표 미갱신(메인 에이전트가 처리).
