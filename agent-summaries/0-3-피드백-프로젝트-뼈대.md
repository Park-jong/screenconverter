## 1단계 주의점
- `setUndecorated(true)`는 displayable 전에 호출.
- 항상 위: `setAlwaysOnTop(true)`, 필요 시 재적용.
- 리사이즈/드래그 직접 구현: 가장자리 6~8px, 8방향 커서, `getLocationOnScreen` 델타, 최소 크기, 순수 함수로 분리.
- 마우스 리스너는 콘텐츠 패널에 부착.
- ESC는 InputMap/ActionMap(WHEN_IN_FOCUSED_WINDOW), 우클릭은 JPopupMenu + pressed/released 양쪽에서 `isPopupTrigger()`. 종료는 `dispose()` 후 `System.exit(0)`.
- per-pixel 투명은 서두르지 않는다(투명 창은 마우스 이벤트가 안 잡히는 함정). 가장자리 알파는 0이 아니게.
- 3단계 대비: 창 클래스를 ui 패키지의 OverlayWindow로 모아 둔다. HWND는 displayable 이후에 얻는다.
- 검증 팁: Robot 합성 마우스 입력으로 드래그/리사이즈를 확인하고 스크린샷으로 제목줄 없음 확인.
