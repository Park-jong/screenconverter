# 3-3 피드백: 자기 창 제외 (feedback-synthesizer 보고, 메인 에이전트가 대신 저장)

근거: 3-1·3-2 요약과 ROADMAP 3단계 기준만 대조(소스는 직접 읽지 않고 요약을 신뢰).

## 판정: 3단계 완료, 추가 루프 불필요 (증거 강도 강함)
- 3-1 정지 상태 전수 비교(5개 상태, 최대 96만 픽셀, 패턴이 화면 좌표 기준이라 위치 오류도 검출), affinity 끈 양성 대조는 bad=전체·켠 상태는 bad=0, 제외된 자리는 검은색이 아니라 뒤쪽 패턴.
- 3-2 동적 760프레임 good=760/bad=0, 음성 대조 good=2/bad=758, 외부 프로세스 GetWindowDisplayAffinity=0x11(5회), Main 경로 하네스 + 오프셋 역산.
- 남는 공백(완료 기준을 뒤집지 않음): ① 사람 눈이 보는 DWM 합성 화면 직접 확인 안 함 → 4단계 육안 검증 때 스크린샷 1장으로 겸함, ② 실제 jar 프로세스의 CapturePanel 내부 이미지 직접 읽기 안 함(대체 증거 충분), ③ 환경이 한 종류(100%, 단일 모니터, Win11 26200).

## 4단계(모자이크) 주의점
- **구조**: `com.converter.effect.Effect` 인터페이스(`BufferedImage apply(BufferedImage src)`, 입력 불변·새 이미지 반환), 구현체 `MosaicEffect(blockSize)`. Swing·JNA·AWT 컴포넌트 의존 금지(순수 로직). 적용 지점은 captureOnce 워커 스레드, 완성된 이미지만 EDT로 넘겨 `CapturePanel.setImage`로 교체(paintComponent에서 연산 금지). 효과 참조는 volatile/불변. 항등 효과로 3단계 동작 유지·회귀 검증 가능해야 함.
- **값**: 기본 블록 10px, 최소 2px, 상한은 캡처 크기 이하 클램프, 검증은 생성자에서. 반환은 같은 크기 TYPE_INT_RGB.
- **알고리즘**: 마지막 열/행 부분 블록은 실제 픽셀 수로 평균(N으로 나누면 어두워짐). 채널별 정수 합 + 반올림 규칙 명시. 축소 후 최근접 확대는 정확한 평균이 아니므로 직접 블록 평균(`getRGB`/`DataBufferInt`)으로 정확성 우선, 성능은 측정 후 결정.
- **성능**: 33ms 안에 캡처+효과. 최대화(1738x1007, 약 175만 픽셀) 1프레임 효과 처리 시간 측정·기록(목표 약 10ms 이하). 이미지 재사용 등 정밀 최적화는 5단계.
- **좌표·크기**: 결과 크기 = 입력(captureRect) 크기, CapturePanel 그리기 좌표(insets)와 1px 어긋남 금지. 블록 격자 원점은 이미지 (0,0) 기준(창이 움직이면 모자이크가 출렁이는 건 정상) — 결정 사항을 기록.
- **자기 창 제외 상태의 의미**: 입력은 '뒤쪽 실제 화면'이며 제목줄·메뉴 칸·테두리는 포함되지 않음. 재귀가 부활하면 affinity 실패 신호 → 4단계 검증에서 `captureExcluded=true` 확인 필수.
- **검증 방법**: ① JUnit: 4x4/블록 2 손계산, 블록 1(원본 동일), 블록이 이미지보다 큼(전체 평균 1색), 크기가 배수 아님(예: 10x7, 블록 4), 단색, 입력 불변. ② 통합: 3단계 좌표 패턴 프레임을 뒤에 깔고 캡처 결과를 블록별로 직접 평균해 기대 이미지를 만들어 전수 비교(bad=0, 오프셋 역산 포함). ③ 동적: 3-2의 5ms 읽기 하네스 재사용, 프레임마다 크기 일치·블록 내부 단색성·평균 일치, 효과를 끈 상태가 실패하는 음성 대조. ④ 육안: 글자가 있는 실제 화면 위 스크린샷(DWM 합성 공백 겸함, 5px 모서리 확인). ⑤ 회귀: 1-8·3-2의 제목줄 이동, 최소 크기 518x221/320x180, 종료 경로 4종, affinity 0x11 외부 확인, java 프로세스 0개.

## code-writer용 피드백 (4-1)
`Effect` + `MosaicEffect(int blockSize)` 신규(기본 10, 최소 2, 입력 불변, 같은 크기 TYPE_INT_RGB), 부분 블록은 실제 픽셀 수로 평균, 워커 스레드에서 적용, 효과는 교체 가능한 volatile 필드로 Main에서 주입, 테스트 추가, win32/* 와 Main 훅 순서는 건드리지 말 것, 최대화 크기 1프레임 처리 시간 보고.
