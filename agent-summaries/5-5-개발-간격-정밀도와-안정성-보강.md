## 변경
- **프레임 대기**(`capture/FramePacer.java`): `SPIN_MARGIN_NANOS`(2ms, 5-3 측정 근거), 순수 함수 `plan(long remainingNanos)` → `SleepPlan(sleepMillis, spinNanos)` — `sleepMillis` = (남은 − 2ms)의 정수 ms, 10의 배수이면 1 감소, 나머지는 스핀, 남은 시간이 2ms 이하·0·음수면 sleep 없음. `awaitUntil(deadline)`은 sleep 후 `Thread.onSpinWait()` 스핀, sleep·스핀 중 interrupt는 `InterruptedException`. `OverlayWindow.captureLoop`에서 `LockSupport.parkNanos`를 `awaitUntil`로 교체, interrupt 시 플래그를 복원하고 루프 탈출, fps=max의 대기는 이전처럼 0.
- **백오프**: `FramePacer.ERROR_BACKOFF_NANOS`=10ms, `withBackoff(wait, failed)`가 실패 직후 대기를 최소 10ms로 올림. `captureOnce`가 `boolean`을 반환(captureRect null, grab이 null, 예외 시 false). max 모드의 정상 프레임은 불변(대기 0).
- **`ErrorThrottle`**: 시계는 기존 `now` 인자(테스트에서 가짜 시간). 키(클래스+메시지)별 마지막 출력 시각·억제 건수를 최대 64키 `LinkedHashMap`에 보관(가장 오래된 키 제거), 전체 출력 상한은 5초 슬라이딩 창에서 10줄(상수, 테스트용 4인자 생성자 있음). `takeSuppressed()`는 전체 건수, `takeSuppressedFor(key)`는 키별 건수 — `OverlayWindow`가 둘 다 출력. 기존 테스트 `differentKeyIsLoggedImmediately`는 키별 기억 때문에 세 번째 호출(`a` 재등장)이 이제 억제되므로 단언을 `assertFalse`로 변경.
- **`EffectPackageImportsTest` allowlist 전환**: `findViolations(source)`가 주석·문자열·문자 리터럴·텍스트 블록을 제거하고 `;`로 분리해 정규식을 import와 본문 완전수식에 적용, `import static`은 마지막 멤버를 뗌, `package` 문은 건너뜀, 정확 일치 항목 뒤에 멤버가 붙어도(`java.awt.Color.RED`) 통과. 현재 effect 소스는 지정한 allowlist 그대로 통과(허용 목록에 추가한 것 없음). 검출기 테스트에 요청한 케이스 전부 포함. `effect/package-info.java`에 allowlist 규칙 명시.
- 신규/확장 테스트: `FramePacerTest`(`plan`: 26.2ms → sleep 24 + 스핀 2.2ms, 12ms → 9, 22ms → 19, 32ms → 29, 정확히 2ms, ≤0, 1ms 미만 sleep, sleep이 10의 배수가 아니고 sleep+스핀=입력인지 반복 검사, `withBackoff`), `ErrorThrottleTest`(번갈아 나오는 키, 카운터 메시지, 같은 키 5초, 맵 제거, 슬라이딩 전체 상한), `EffectPackageImportsTest`.
