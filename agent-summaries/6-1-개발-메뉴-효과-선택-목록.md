# 6-1 개발: 메뉴 효과 선택 목록 (code-writer 보고, 메인 에이전트가 대신 저장)

사용자 요청: "메뉴에 지금 개발된 효과들을 선택하고 선택된 것이 무엇인지 보이게 해줘". `mvn -B package` BUILD SUCCESS, 테스트 73개 통과(신규 `MenuPanelTest` 8개 포함). 창을 직접 띄워 클릭·숫자 키·ESC 확인, java 프로세스 잔존 없음. 최소 크기 스크린샷은 파일 픽셀값으로만 확인했고 육안 확인은 640x360 기준. 리뷰 판정 없음.

## 변경 파일
`ui/MenuPanel.java`(전면 교체), `ui/OverlayWindow.java`, `test/.../ui/MenuPanelTest.java`(신규). ROADMAP.md는 수정하지 않음(6단계 행에 이미 6-1 항목이 있음). 미변경: win32/*, effect/*, 훅 순서, closeApp, 창 장식, captureOnce, CapturePanel, MinimumWindowSize.

## 동작
- **목록**: `MenuPanel(EffectRegistry)`가 entries를 읽어 "1  원본" … "9  ASCII 아트" 행 구성(하드코딩 없음). 상단에 굵은 흰 글씨 "현재: 모자이크" 헤더.
- **강조**: 선택 행은 파란 배경(38,110,200) + 흰 굵은 글씨, 나머지는 밝은 회색(200,200,200), 배경 (30,30,30), hover (60,60,60). 글꼴 Malgun Gothic(없으면 Dialog 대체), 한글 정상 출력.
- **클릭**: 행 클릭 시 `OverlayWindow.selectEffect(번호)`(효과 교체 + 제목 갱신). 이미 선택된 행 재클릭은 무동작.
- **동기화**: `selectEffect` 성공 시 `menu.setSelected(number)`(EDT면 즉시, 아니면 invokeLater). 숫자 키·코드 호출·Main의 `selectEffect(2)` 모두 이 경로. `setSelected`는 내부 플래그로 리스너를 호출하지 않음(루프 방지). 미등록 번호는 false 반환, 표시 불변.
- **초기 상태**: MenuPanel은 1번(원본) 선택으로 시작하고 Main의 `selectEffect(2)`로 모자이크 강조. 시작 직후 "현재: 모자이크"와 2번 행 강조 확인.
- **크기**: MenuPanel preferred 폭 180 단일 출처 유지. 행 18px + 헤더 18px로 9개가 들어가고, JScrollPane으로 감싸 9개 초과 시 스크롤(세로 스크롤바 필요 시만, 어두운 단색 8px 얇은 스타일 — **스크롤바는 코드만 작성했고 화면에서 본 적 없음**). 메뉴 높이를 `MinimumWindowSize`에 반영하지 않았고 그 테스트도 갱신하지 않음.
- **순수 로직**: static `indexOf`/`numberOf`/`label`로 분리해 단위 테스트. 테스트용 접근자는 `Component.list()`와 이름이 겹쳐 `effectList()`로 명명.

## 키보드 포커스
목록·스크롤 패널·스크롤바 모두 `setFocusable(false)` — type-ahead/화살표 키가 숫자·ESC를 가로채지 않음. Robot 실측(640x360): 6번 행 클릭 → 제목 "도트 게임보이", isActive=true. 이어서 숫자 8 → "도트 16색+격자", 숫자패드 3 → "흑백", 9 → "ASCII 아트", ESC → 종료 코드 0. **관찰**: 메뉴 클릭으로 창이 활성화되어 캡처 영역을 따로 클릭하지 않아도 이후 키가 먹음 — 기존의 "창을 한 번 클릭해야 키가 먹는다" 제약이 메뉴 클릭으로 완화됨.

## 최소 창 크기(518x221) 실측
메뉴 칸 180x182(헤더 18 + 목록 162(9x18) = 180, 뷰포트 164 → 9행 모두 보이고 스크롤바 없음, 마지막 행 아래 2px 여유). 640x360에서는 메뉴 180x321. 스크린샷은 scratchpad의 `p-640.png`, `p-min.png`. 오버레이 창에 캡처 제외가 걸려 Robot 화면 캡처에는 뒤쪽 터미널만 찍혀(menu-*.png는 사용 불가), MenuPanel을 실제 창 크기로 BufferedImage에 직접 paint해 저장함. 640x360 이미지 육안: 어두운 배경에 헤더 "현재: 모자이크", 2번 행이 파란 띠 + 흰 굵은 글씨. **최소 크기 이미지는 이 환경 뷰어에서 파란 띠가 안 보였으나 저장된 파일의 2번 행 중앙 픽셀이 0xFF266EC8(파란색)이라 뷰어 표시 문제로 판단 — 육안으로는 직접 확인하지 못함.**
