# 4-5 검증: 흑백 효과와 전환키 (code-verifier 보고, 메인 에이전트가 대신 저장)

판정: 차단/중대 문제 없음, 요구 항목 전부 통과. 소스 수정 없음. 환경: Win11, 배율 100%, 단일 모니터.

## 빌드·코드 리뷰
- `mvn -B clean package` BUILD SUCCESS, 테스트 27개 통과(실패·에러·스킵 0).
- GrayscaleEffect: `(299r+587g+114b+500)/1000`, 알파 무시, 출력 TYPE_INT_RGB, 입력 불변, threshold 0..255(-1·256은 IAE), `gray >= threshold` → 255 아니면 0. EffectRegistry: 번호 1부터, 0/-1/5/9는 `Optional.empty`, 순서 원본·모자이크·흑백·흑백 2색, `register`는 다음 번호.
- OverlayWindow: `installEffectKeys`는 1~9의 `VK_0+n`과 `VK_NUMPAD0+n`을 `WHEN_IN_FOCUSED_WINDOW`(ESC와 같은 방식)로 묶고 EDT에서 `selectEffect(n)` 호출, 미등록 번호 무시. `effect` volatile. `selectEffect`는 `setTitle`만 호출 — 실측에서 HWND·스타일·확장 스타일·경계 모두 불변. Main: `selectEffect(2)`가 `setVisible` 이전 EDT에서 호출, 훅 순서 불변. effect 패키지 jna/swing import grep 0건. 3단계 파일 수정 시각이 OverlayWindow보다 앞서 변경 흔적 없음(git 없어 diff 불가).

## 단위 테스트·정수식 전수 검사
- 손계산 대조: (255,0,0)→76, (0,255,0)→150, (0,0,255)→29, 흰 255, 검 0 모두 일치(코드 주석의 소수 값은 +500 이전 값). 알파 0 빨강 → 4c4c4c(알파 무시), null 입력 NPE, TYPE_BYTE_GRAY 입력 정상.
- 16,777,216개 전 조합에서 정수식과 BigDecimal 정확 계산 일치(b 5 간격 샘플링, mismatch 0). 구현 출력은 정수식 기대값과 100% 일치, 2색 모드·R=G=B 위반 0.
- 단순 `double` 식 `floor(0.299R+0.587G+0.114B+0.5)`는 3,464개 조합에서 1 낮게 나옴 — 정확히 `.5`인 경계(S+500이 1000의 배수, 전체 16,782개 중)의 부동소수 오차로, 예: (0,36,12) → 구현 23, double 22. 구현이 맞고 double 식이 틀림(정보 수준). 2색 128 경계(gray=127.5)도 정수 기준이 정확. 검증 하네스는 `+1e-9` 보정으로 비교.

## 통합 검증 (Main 경로, 좌표 패턴 창 위)
captureExcluded=true, GetWindowDisplayAffinity=0x11, alwaysOnTop=true, 초기 제목 `Converter - 모자이크`(Win32 GetWindowText로도 확인). `selectEffect(1~4)` 각각 × 6개 크기 + 최대화(1738x1007)를 CapturePanel.image와 독립 기대 이미지로 전수 비교: 28케이스 12,726,176픽셀 bad=0(518x221 최소·홀수 641x361 포함, 캡처 최소 320x180, 모자이크 기대값은 정수 반올림으로 독립 계산). 흑백 R=G=B, 2색은 0/255뿐. `selectEffect(5/0/-1/10)`은 false·제목 불변. 음성 대조: 항등으로 바꾸고 흑백 기대와 비교 시 bad=140,996 FAIL·R=G=B 속성 FAIL.

## 실제 키 입력
인-프로세스 Main 경로에서 Robot으로 패널 클릭(focused=true) 후 키 1,2,3,4,5,0,9, 숫자패드 1~5, A: 1~4와 숫자패드 1~4는 제목(Java·Win32 모두)과 이미지가 해당 효과로 바뀌고 직후 bad=0, 5/0/9/숫자패드 5/A는 무시. 전후 HWND·스타일(0x16cf0000)·확장 스타일(0x108)·경계 동일, affinity 0x11 유지. 실제 `java -jar` 별도 프로세스에서도 클릭 후 1,2,3,4,5,숫자패드 1·3,9 모두 기대 제목(5·9 무시).
