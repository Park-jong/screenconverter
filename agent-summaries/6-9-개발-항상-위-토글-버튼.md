# 항상 위 토글 버튼 추가

## 변경 파일
- src/main/java/com/converter/ui/MenuPanel.java: FlatButton 기반 "항상 위" 토글(기본 켜짐, 켜짐은 파란 눌림 + "항상 위: 켜짐", 꺼짐은 일반 + "항상 위: 꺼짐", setFocusable(false)). `setAlwaysOnTopListener(Consumer<Boolean>)`(클릭 시에만 호출), `setAlwaysOnTopState(boolean)`(리스너 미호출). 복사 버튼 아래·상태 줄 위에 배치, preferred 높이에 GAP+BUTTON_HEIGHT(28px) 반영. 키 바인딩 추가 없음.
- src/main/java/com/converter/ui/OverlayWindow.java: 생성 시 `menu.setAlwaysOnTopState(isAlwaysOnTop())` 동기화 후 리스너 연결. `applyAlwaysOnTop` 은 `setAlwaysOnTop(value)` 만 호출하고, RuntimeException 이면 stderr 로그 + 버튼 상태 복구 + 상태 줄 "항상 위 변경 실패".
- src/test/.../MenuPanelTest.java: 높이 기대값 +28 갱신, 새 테스트 2개(기본 켜짐/클릭/상태 설정 무통지/비포커스, 문구 폭).

## 결과
- mvn -B package: 177 테스트 통과, BUILD SUCCESS.
- 스모크: java -jar target/converter.jar 5초 실행, stdout/stderr 0바이트, 자기 프로세스만 종료.
- 메뉴 preferred 높이 332 -> 360. 새 최소 창 크기 약 518 x 399 (이전 518x371, 높이 +28, 프레임 인셋 기준 계산값).

## 하지 않은 것
- 실제 창에서 토글 동작·화면 확인, Robot/스크린샷/성능/회귀 시험(검증 단계 몫). SecurityException 경로는 단위 시험 안 함.
