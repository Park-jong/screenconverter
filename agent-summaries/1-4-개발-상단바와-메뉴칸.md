# 1-4 개발: 상단바와 메뉴칸 (code-writer 보고, 메인 에이전트가 대신 저장)

사용자 요청: (1) 일반 창처럼 상단 제목 표시줄 유지, (2) 오른쪽에 나중에 기능을 넣을 메뉴 칸.

`mvn -B package` BUILD SUCCESS, 테스트 3개 통과(ResizeLogicTest 7개 삭제로 감소, 남은 것은 CaptureRegionTest 3개). `java -jar` 4초 실행 시 프로세스 유지, stderr 0바이트, 이후 강제 종료(java 프로세스 0개). 창 육안 확인, ESC·닫기 버튼·우클릭 '닫기', 캡처 좌표 실측은 개발 단계에서 미확인.

## 변경
- `ui/OverlayWindow.java`: `setUndecorated(true)` 제거(OS 기본 제목줄·테두리, 장식은 생성자에서만 지정). CENTER=CapturePanel, EAST=MenuPanel, 초기 640x360, 최소 400x250. 직접 구현한 드래그 이동·8방향 리사이즈·커서 변경 코드 삭제. 우클릭 '닫기' 팝업은 `installPopup()`으로 CapturePanel에 유지. captureRect는 `CapturePanel.getLocationOnScreen()` + `CaptureRegion.inner`로 계산, 창과 CapturePanel 양쪽에 같은 ComponentAdapter 부착. 닫기 버튼은 `DO_NOTHING_ON_CLOSE` + `windowClosing`으로 `closeApp()`(shutdownNow → dispose → System.exit(0)). 유지: alwaysOnTop, ESC(WHEN_IN_FOCUSED_WINDOW), `setShownHook`/`onShown`, `ScreenGrabber`, 33ms 워커 `captureOnce`.
- 신규 `ui/MenuPanel.java`: 폭 180px, 배경 (30,30,30), "메뉴(준비 중)" 라벨만 있는 빈 패널.
- 삭제: `ui/ResizeLogic.java`, `test/.../ResizeLogicTest.java`.
- 미수정: CapturePanel, CaptureRegion, Main. JNA 호출 없음.

참고: `1-1-*.md`, `1-3-*.md` 의 ResizeLogic·직접 리사이즈 관련 서술은 이 변경으로 낡은 내용이 됨.
