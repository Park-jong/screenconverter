# 1-1 개발: 오버레이 창 (code-writer 보고, 메인 에이전트가 대신 저장)

`mvn -B package` BUILD SUCCESS, 단위 테스트 7개 통과(실패·에러·스킵 0), target/converter.jar 생성. 개발 단계에서는 창을 실제로 띄워 확인하지 않음.

## 변경 파일
- `pom.xml`: junit-jupiter 5.10.2(test), maven-surefire-plugin 3.2.5 (버전 명시 고정)
- `src/main/java/com/converter/ui/ResizeLogic.java`: UI와 분리된 순수 로직
  - `Edge` enum (NONE, N/S/E/W/NE/NW/SE/SW)
  - `hitTest(x, y, w, h, border)`: 모서리를 변보다 우선 판정
  - `move(start, dx, dy)`, `resize(start, edge, dx, dy, minW, minH)`: 반대편 고정, 최소 크기 제한
- `src/main/java/com/converter/ui/OverlayWindow.java` (JFrame 상속)
  - `setUndecorated(true)` 먼저, 이후 `setAlwaysOnTop(true)`. 기본 400x300, 최소 60x60, 가장자리 판정 7px
  - 불투명 단색 콘텐츠 패널 + 1px 테두리 (per-pixel 투명, 클릭 통과 없음)
  - 마우스 리스너는 콘텐츠 패널에 부착, `getLocationOnScreen` 델타로 이동·리사이즈, 방향별 커서
  - ESC: InputMap/ActionMap(WHEN_IN_FOCUSED_WINDOW). 우클릭 JPopupMenu '닫기'(pressed/released 양쪽에서 isPopupTrigger)
  - 종료: `dispose()` 후 `System.exit(0)`
- `src/main/java/com/converter/Main.java`: EDT에서 OverlayWindow 실행
- `src/test/java/com/converter/ui/ResizeLogicTest.java`: JUnit 5 테스트 7개 (8방향 판정, 내부/바깥, 이동, 리사이즈, 최소 크기)

---
> 주의(1-4 이후): ResizeLogic과 직접 구현한 드래그·리사이즈 서술은 폐기됨. 창은 OS 기본 제목줄을 쓰고 이동·리사이즈는 OS가 처리한다. 상세는 1-4, 1-6 요약 참고.
