# 4-2 검증: 모자이크 효과 (code-verifier 보고, 메인 에이전트가 대신 저장)

판정: 심각/높음/중간 문제 없음. 통합·동적 검증 모두 bad=0, 음성 대조 2종은 의도대로 FAIL. 소스 수정 없음. 환경: Win11 26200, 배율 100%, 단일 1920x1080 모니터.

## 빌드·코드 리뷰
- `mvn -B clean package` BUILD SUCCESS, 테스트 18개 통과.
- MosaicEffect: 격자 원점 (0,0), 마지막 열/행은 실제 픽셀 수(rows*cols)로 나눔, 반올림 `(sum+count/2)/count`(half-up), 채널 합은 long(1738x1007에서도 int 오버플로 없음), 입력 `getRGB` 복사로 불변, 출력 TYPE_INT_RGB `DataBufferInt` 직접 쓰기, w==0 또는 h==0은 빈 이미지, blockSize<2는 IllegalArgumentException.
- IdentityEffect: 정확한 복사본. effect 패키지 import는 BufferedImage·DataBufferInt·java.util 뿐(jna·swing·AWT 컴포넌트 grep 0건).
- OverlayWindow: `captureOnce`(capture-worker)에서 `effect.apply` → 완성 이미지만 invokeLater로 `CapturePanel.setImage`, paintComponent에는 연산 없음, 예외는 기존 `catch (RuntimeException)`(코드로만 확인, 실제 예외를 던져 실행하지는 않음), `effect` volatile·`setEffect` null 거부. Main: `setEffect(new MosaicEffect(10))`는 `new OverlayWindow()` 직후, 훅 순서 불변. 3단계 파일은 수정 시각상 4단계에서 건드린 흔적 없음(git 없어 diff 불가).

## 단위 테스트 독립 재검토
4x4·블록 2 손계산(6/1/1, 10/0/7, 20/0/0, 255/4=63.75→64)과 10x7·블록 4 코너 블록 351/6=58.5→59가 모두 맞음. 한계: 10x7 전수 비교 테스트는 기대 공식이 구현과 같아 반올림 규칙에 대해 부분적으로 순환 검증(하드코딩 손계산 값이 따로 있어 치명적이지 않음). 블록 1 테스트는 최소 2로 설계가 바뀌어 거부 테스트로 대체됨.

## 통합 검증
전체 화면 좌표 패턴(B.java) + `Main.main` 경로, CapturePanel `image`·`captureRect` 리플렉션. 기대 이미지는 검증자가 T.java에서 `floor(sum/n+0.5)` 실수 방식으로 독립 구현. captureExcluded=true, alwaysOnTop=true. 8케이스 정지 비교 모두 bad=0 (640x360→442x319, 733x417→535x376, 901x555→703x514, 100x100 시도→518x221·320x180, 518x221, 1000x700→802x659, 641x361→443x320, 최대화→1738x1007), 이미지 크기 = captureRect, 타입 INT_RGB, 블록(10)의 배수가 아닌 크기 다수 포함.

## 동적 검증
5ms 주기로 이미지 참조 변경 감지, 프레임마다 (i) 크기가 captureRect history와 일치 (ii) 블록 내부 단색성 (iii) 독립 계산 평균 일치. setBounds 반복, setLocation 30회, 100x100 리사이즈, 최대화, 복원, Robot 제목줄 드래그·가장자리 리사이즈 2라운드. 498프레임 모두 good (nonsolid=0, avgMismatch=0, sizeMismatch=0), PASS. 음성 대조 1(IdentityEffect): 484프레임 전부 nonsolid, 정적 8/8 FAIL. 음성 대조 2(affinity 미적용): 495프레임 전부 avgMismatch(자기 창 재캡처), 정적 8/8 FAIL.

## 육안
그라데이션, 흰 원, 노란 사각형, 둥근 초록 사각형, 큰 글씨 "Hello Mosaic 모자이크", 작은 모노스페이스 문장이 있는 창 위에 오버레이 800x560을 올려 CapturePanel이 그린 이미지를 저장(scratchpad의 v_content_paint.png, v_panel_image.png, 비교 원본 v_robot.png). 그라데이션은 10px 블록 단계, 원 가장자리는 블록 계단과 혼합색, 큰 글씨는 읽을 수 없는 어두운 블록 덩어리, 작은 글씨는 줄무늬 블록 — 모자이크로 보임, 완료 기준 충족. 한계: DWM이 합성한 실제 화면을 직접 찍지는 못함(오버레이가 0x11이라 일반 캡처에서 제외됨, 패널 paint 결과·이미지 리플렉션으로 대체). 5px 둥근 모서리는 확인 못 함.
